## Resultado entregado

La demostración integra el honeypot, la captura y normalización de telemetría, el motor de correlación y reconstrucción causal, la persistencia privada de análisis, la API de consulta, la interfaz de visualización y la CLI de escenarios controlados. El repositorio incluye pruebas automatizadas y scripts de despliegue para reproducir el entorno de laboratorio.

## Límites declarados

El cierre no afirma la ejecución del piloto institucional propuesto en OTI UNI ni una aceptación física sobre Raspberry Pi que no esté documentada con evidencia de campo. Esas actividades, junto con una evaluación cuantitativa ampliada contra *ground truth*, se conservan como extensiones posibles y no bloquean el estado final del proyecto presentado en UNITEC 2026.

## Conservación

Los ADR, sprints y planes de prueba mantienen las decisiones y propuestas históricas. Cuando un documento histórico difiera de este registro, este archivo y el README principal representan el estado final del proyecto.
