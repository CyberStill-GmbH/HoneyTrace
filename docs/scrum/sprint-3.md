# Sprint 3 — Escenarios, comparación y Raspberry Pi

## Duración

1–5 de septiembre de 2026.

## Objetivo

Evaluar los cinco escenarios, preparar el dispositivo físico y cerrar las condiciones institucionales de la prueba.

- [ ] **LT** — extender correlación y reconstrucción a IDOR, SQLi, Path Traversal y Stored XSS.
- [ ] **IA** — crear fixtures, ground truth y bitácoras para los cuatro escenarios restantes.
- [ ] **IA** — completar matriz pregunta–métrica–dataset–resultado y redactar limitaciones.
- [ ] **IB** — preparar Raspberry Pi OS 64 bits, Docker y usuario sin privilegios.

- [ ] **Equipo** — completar un ensayo continuo mínimo de 2 horas sobre el hardware.

## Criterio de salida

Los cinco escenarios tienen evidencia y ground truth; la Pi opera con margen; y OTI UNI confirmó por escrito alcance, responsable y ventana. Sin autorización o aislamiento verificado, el sprint termina en **No-Go para campo** aunque el software continúe.
